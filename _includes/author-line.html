{% comment %} Author line for a publication (list entry, its own page, homepage): initials without full stops, then surname, separated by commas — "K Marais, JA Smith, T Ndlovu". Built from `authors` via _includes/author-parse.html, so `authors` can be written with full names (and is, so the Cite formats that use full first names can). Your name is bold when its "Surname, Given" form contains `site.publication_author` ("Marais, K").
