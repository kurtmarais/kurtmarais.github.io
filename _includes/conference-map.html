{% comment %} Conference map panel for the Engagements page (toggled by the MAP control in the filter row; behaviour in assets/js/conference-map.js). Coastlines, graticule and outline are pre-rendered static SVG paths: Equal Earth projection, d3-geo geoEqualEarth().scale(155).translate([450,230]) on world-atlas land-110m, viewBox 0 0 900 460. No runtime map library. Dots come from _data/engagements.yml: every entry with a `map:` block (city, region, lat, lon). The JS projects lat/lon with the same Equal Earth formula and scale, so dots line up with these coastlines. One dot per region (the most recent engagement there); earlier ones in the same region are listed in the card. {% endcomment %} {% assign ecm_entries = site.data.engagements | where_exp: "e", "e.map" %}
