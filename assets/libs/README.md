# assets/libs/

Vendored third-party libraries — don't hand-edit; to upgrade, replace the
whole subfolder with the new release.

- `bootstrap/` — Bootstrap CSS (grid/utilities only; no Bootstrap JS).
- `fontawesome/icons.min.js` — what pages normally load (via
  `assets/js/fa-loader.js`): `all.min.js` with only the icons the site
  uses, generated by `tools/fa-subset.js`. A GitHub Action
  (`.github/workflows/icon-subset.yml`) regenerates it on every relevant
  push to main, so adding an icon needs no extra step. Don't edit it by hand.
- `fontawesome/all.min.js` — **Font Awesome Free 6.7.2**, JS/SVG build, the
  full set. Source for the subset, and the fallback the loader uses on a
  page whose icons aren't all in the subset yet. To upgrade Font Awesome,
  replace this file; the Action rebuilds the subset. There
  is no Font Awesome CSS file: the script replaces each `<i class="fa…">`
  with an inline `<svg>` after load, so CSS must target `svg` as well as `i`
  (see `_sass/README.md`).

To check whether an icon name exists in this version, search the full file
(e.g. `grep -c '"users-rectangle"' fontawesome/all.min.js`) rather than the
Font Awesome website, which lists newer and Pro-only icons.
